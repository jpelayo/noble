Get Started

Set up your NOBLE node in minutes.

1

Download

Download the latest NOBLE node binary for your platform from the Downloads section.

2

Run Setup

Launch the interactive setup wizard: noble-node setup. Choose your role (validator/gateway/archive), configure ports, and create your wallet.

3

Start Your Node

Start the node daemon: noble-node run. The embedded dashboard is available at http://127.0.0.1:8785.

4

Register Documents

Use the dashboard GUI or JSON-RPC API to register document checksums. Each registration creates an immutable on-chain record.

5

Verify Anytime

Anyone can verify a document by computing its SHA-256 checksum and querying the network — no account required.

About NOBLE

A blockchain for trust, not speculation.

NOBLE (Neutral Open Blockchain Environment) is a purpose-built blockchain protocol designed by InfiniteContext for document registration, verification, and notarization. Unlike general-purpose blockchains, NOBLE focuses on a single mission: providing tamper-proof, timestamped proof of document existence.

The protocol uses Proof of Reputation consensus, where validators earn reputation through honest participation rather than energy-intensive mining. This provides fast 16-minute cycle finality while maintaining decentralization and security.

NOBLE supports secp256k1 cryptography, Bitcoin-compatible wallet import (BIP-39/BIP-137), organizational PKI identity binding (X.509/CMS), and encrypted document locators for privacy-preserving verification.
